Chamados TI projeto de portfólio

Sistema de Chamados TI

Uma prévia do sistema que desenvolvi para simular a rotina de uma equipe de suporte técnico: abertura de chamados, acompanhamento de status e um painel com estatísticas reais de atendimento.

Projeto pessoal · PHP · Suporte técnico

Objetivo do projeto

Esse sistema foi pensado em como uma equipe de TI organiza, na prática, o suporte técnico do dia a dia.

  • Registrar chamados de suporte técnico de forma estruturada (solicitante, setor, categoria, prioridade)
  • Acompanhar o status de cada chamado até a conclusão
  • Gerar visão gerencial: estatísticas por categoria, por setor e tempo médio de atendimento
  • Aplicar boas práticas básicas de segurança no acesso ao banco de dados

Tecnologias utilizadas

Linguagem back-end
PHP
Lógica do sistema e geração dinâmica das páginas
Banco de dados
SQLite / MySQL
Acesso via PDO com prepared statements, prevenindo SQL Injection
Front-end
HTML5 + CSS3
Interface própria, sem frameworks, focada em clareza para uso interno
Arquitetura
Páginas separadas por função
Painel, listagem e formulário de abertura em arquivos independentes
